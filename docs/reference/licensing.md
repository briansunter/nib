# Licensing

Status: current

Last reviewed: 2026-07-28

The repository does not currently grant an open-source license. Both npm
package manifests therefore use the standard `UNLICENSED` marker. Publishing
access and source visibility do not themselves grant permission to copy,
modify, or redistribute the code.

If the project adopts an open-source license later, add the corresponding
license file and update both package manifests in the same release.
