## Overview

A gallery of my drawings and paintings, grouped into series by medium and theme. Each piece carries its own metadata (medium, surface, dimensions, year), so the gallery doubles as a record of practice over time.

## Features

- Series organized by medium and theme
- Full-screen lightbox via PhotoSwipe
- Per-piece metadata (medium, surface, dimensions, year)
- Filter by tag and medium
- Grid and list views
- Drafts hidden in production

## Technology Stack

- YAML files for artwork metadata
- PhotoSwipe for the lightbox
- Astro content collections for type-safe loading
- Tailwind CSS, TypeScript
