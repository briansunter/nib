# PostcardPop

## Overview

PostcardPop is a small web app for making digital postcards. Pick a front image, flip the card over, write a note, add a recipient and sender, stamp it with a map location, then copy a share link to send the finished postcard.

## Features

- Flip-card postcard layout with editable front and back sides
- Custom front image via any hosted image URL
- Personal message, recipient, sender, and location fields
- Map stamp powered by Leaflet and OpenStreetMap tiles
- Address geocoding with Nominatim
- Shareable postcard links encoded in the URL
- Light and dark themes
- First-run tutorial and received-card flip hint

## Technology Stack

- React 19 + TypeScript
- Vite
- Bun
- Leaflet and React Leaflet
- Vitest and Testing Library
- Cypress for end-to-end tests
- GitHub Pages deployment
