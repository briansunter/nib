# Moodboard

An infinite-canvas moodboard with sticky notes and images. Pan, zoom, drop things wherever they make sense.

[Visit Project](https://moodboard.briansunter.com)

project Bun React TypeScript Konva TanStack Router

![Cover image for Moodboard](/_astro/moodboard-hero.CECE6X0a_Z1vptju.webp)

## Overview

An infinite-canvas board for sticky notes and images. No grid, no hierarchy. Just a surface big enough that you can lay things out spatially the way you’d think about them on a wall.

## Features

- Infinite pan and zoom
- Sticky notes with rich-text editing
- Image upload and placement
- Drag and drop arrangement
- Works on desktop and mobile

## Technology Stack

- Bun
- React 18 + TypeScript
- Konva.js for canvas rendering
- TanStack Router for file-based routing
- Tailwind CSS
