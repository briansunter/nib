## Overview

Tracer turns your phone or tablet into a tracing surface. Load a reference image, set its opacity, and draw on top of it. This approach is useful for learning to draw by copying master works, the same way figure-drawing classes have used lightboxes forever, just without the lightbox.

## Features

- Import any image as a reference layer
- Adjustable reference-layer opacity
- Brush tools with size and color controls
- Save and export traced work
- Touch input on mobile
- Dark theme for low-light practice

## Technology Stack

- React + TypeScript
- HTML5 Canvas
- Touch event handling for mobile
- Responsive layout
