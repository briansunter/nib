## Features

- **Build automation** via `justfile`: compile to PDF, SVG, and PNG with a single command
- **Live preview** with `just watch` for rapid iteration
- **Customizable**: edit colors, fonts, and content directly in Typst source
- **High-res output**: 300 PPI PNG exports for crisp previews
- **Template scaffold**: `just new-template` to create new designs from scratch

## Tech Stack

- **Typst**: modern markup-based typesetting system (successor to LaTeX for document design)
- **Just**: command runner for build automation
- **ImageMagick**: post-processing and format conversion
